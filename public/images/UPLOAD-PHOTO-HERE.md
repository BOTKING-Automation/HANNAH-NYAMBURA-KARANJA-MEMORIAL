## How to upload

1. Open the repository's `public/images` folder.
2. Select **Add file → Upload files**.
3. Select the photograph from your device.
4. Rename it to one of the exact filenames above (keep the `.jpg` extension only if the file really is a JPEG).
5. Commit the upload to the `main` branch.

If the original photo is a PNG, either convert it to JPEG before naming it `.jpg`, or keep the `.png` filename and ask for the page's image path to be updated. Do not rename a PNG to `.jpg` without converting the file.
