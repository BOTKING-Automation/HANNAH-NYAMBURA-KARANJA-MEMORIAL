How to Edit
the Memorial

You can help preserve Hannah's memory by carefully updating stories, family-approved photographs and words of remembrance. This is a multi-page website, and every thoughtful detail should honour her truth and the love people carry for her.

Every page has its own HTML file. Edit the page you need, preserve the family's voice, and save your change. Because this memorial holds real memories and real grief, check names, dates, photographs and personal stories with the family before publishing. GitHub Pages can publish the updated site after deployment completes.

How to edit code in GitHub

  1. Open the memorial repository.
  2. Open the public folder and choose a file such as story.html.
  3. Click the pencil icon to edit the file. If you do not see it, check that you are signed into an account with write access.
  4. Use Ctrl+F to find the sentence or bracketed placeholder you want to change.
  5. Edit the text but keep HTML tags such as <p>, <h2>, and </p> in place.
  6. Click Commit changes. Allow the Pages deployment to finish before checking the live site.

Photo folder and exact file names

Upload family-approved image files to public/images/. The homepage and gallery already reference these paths:

  • images/hannah-nyambura-karanja.jpg — main portrait on the homepage
  • images/hannah-portrait-2.jpg — second portrait
  • images/hannah-family.jpg — family photograph
  • images/hannah-faith.jpg — faith or community memory
  • images/hannah-smile.jpg — happy memory
  • images/hannah-celebration.jpg — celebration
  • images/hannah-legacy.jpg — legacy photograph

Use the exact file names or edit the HTML to match your names. A PNG file should keep its real .png extension; do not simply rename it to .jpg. To upload: open public/images/ in GitHub, choose Add file → Upload files, select the photo, then commit.

What still needs family input?

  • Hannah's birth date and birthplace, if the family wants them displayed.
  • Personal milestones, relatives' names, church and community details, and specific memories.
  • Confirmed funeral service date, time, venue, directions and approved contact details.
  • Family-approved tributes and acknowledgements.
Accuracy and privacy: The pages avoid inventing personal history. Replace bracketed text only with confirmed details, and get permission before publishing photographs, names, contact information or tributes. The tribute page is static: it does not automatically store form submissions.

Change the design

Shared colours, typography, spacing and responsive layouts are in public/theme.css. Changes there can affect every page. Make a copy of the current text before a major edit so you can undo mistakes.

Publishing

The repository contains a GitHub Actions workflow at .github/workflows/deploy-pages.yml to publish the public directory to GitHub Pages. Check the repository's Actions tab for the latest deployment status. The first deployment may require GitHub Pages to be enabled for the repository in Settings → Pages. GitHub changes do not automatically update the separate Hatchable site unless you deliberately configure a connection.
