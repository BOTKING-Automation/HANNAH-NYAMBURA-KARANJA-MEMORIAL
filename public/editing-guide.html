How to change the wording

  1. Open the repository and select the public folder.
  2. Open the page you want to edit, such as eulogy.html.
  3. Click the pencil icon labelled Edit this file.
  4. Use Ctrl+F to find a sentence or placeholder. Change the text, keeping the surrounding HTML tags intact.
  5. Click Commit changes and save to the main branch.
  6. Refresh the hosted site after deployment completes. GitHub updates will only appear on the live Hatchable site if a deployment connection has been configured.

Replace funeral placeholders

Open service.html and replace items such as [Add confirmed date], [Add venue / burial place], and other bracketed text with details confirmed by the family.

Add Hannah's photographs

Upload family-approved photos to public/images/. In gallery.html, replace a placeholder card with an image element. For example:

<img src="images/hannah-portrait.jpg" alt="Hannah Nyambura Karanja (Wa Ruth)">

Print the eulogy

Open the Full Eulogy page and press Print / Save as PDF. In the print dialog, select Save as PDF.

Please remember: The eulogy is a draft based on the details shared so far. Add personal memories only when they are true and family-approved. The tribute form does not store or publish messages.
