# Hannah Nyambura Karanja (Wa Ruth) Memorial

A premium, faith-centered multi-page memorial website honoring Hannah Nyambura Karanja (Wa Ruth).

## Pages
- `public/index.html` — home / memorial landing page
- `public/story.html` — biography and life story
- `public/eulogy.html` — full eulogy draft, printable or savable as PDF
- `public/service.html` — editable funeral and burial details / order of service
- `public/gallery.html` — family photo gallery placeholders
- `public/tributes.html` — tribute form (prepares a message locally; does not publish or store it)
- `public/theme.css` — shared design system and responsive styling
- `public/app.js` — tribute form interaction

## Edit the site
See [EDITING-GUIDE.md](EDITING-GUIDE.md). All unconfirmed dates, locations, and family history are clearly marked as placeholders; confirm them with the family before publishing.
